01 · Introduction

The Autopilot Labs API.

The Autopilot Labs API is a JSON-over-HTTPS interface for running our vertical AI agents against your workflows. You use it to automate with AI at the outcome level — kick off agent runs, stream progress, subscribe to events, audit every decision, and reconcile against your invoice.

Every resource is backed by the same billing, SLA, and audit primitives that power the Autopilot Labs ops console. If it's in the dashboard, it's in the API.

Base URL

HTTP · Base URL
https://api.autopilotlabs.io/v1

Conventions

  • All requests are HTTPS. Plain HTTP is rejected at the edge.
  • All request and response bodies are JSON, UTF-8 encoded.
  • All timestamps are ISO 8601 in UTC. Clients should render locally.
  • All IDs are stable, prefixed strings: agt_, run_, out_, inv_, whk_.
  • Monetary fields are integer minor units (e.g. cents) paired with a currency code.
  • Pagination is cursor-based via ?cursor= and ?limit= (max 200).

Regions

The API is served from three regions. Your tenancy is pinned to one region at contract time, but the API hostname stays the same — the edge routes to your home region automatically.

RegionCodeData residency
Australiaau-se1Sydney · default for AU/NZ tenants
United Statesus-ea2Virginia · default for AMER tenants
Europeeu-we1Dublin · default for EMEA tenants

Rate limits

Default limit is 1,200 requests per minute per API key, burstable to 2,000 for 10 seconds. Outcome creation is separately capped at your contracted monthly volume. Limits are returned on every response:

HTTP · Headers
X-RateLimit-Limit: 1200
X-RateLimit-Remaining: 1184
X-RateLimit-Reset: 1713254400
NoteEvery request is logged to your audit trail for 7 years. You can redact PII fields per-request with the X-Autopilot Labs-Redact header. Audit entries are immutable and signed.
02 · Authentication

Authentication.

Autopilot Labs supports two authentication modes. Use OAuth 2.0 client-credentials for server-to-server calls from your own backend. Use a static API key for operator tools and one-off scripts. Both scopes map to the same permissions model.

API keys

API keys are issued per workspace from the ops console. Pass them as a bearer token. Keys are scoped (read, write, admin) and rotatable without downtime.

cURL · Example request
# Authenticate with an API key
curl https://api.autopilotlabs.io/v1/agents \
  -H "Authorization: Bearer sk_live_aG8uNxVq9kL2mR4pT7wZbY3" \
  -H "X-Autopilot Labs-Workspace: ws_meridian_health" \
  -H "Accept: application/json"

OAuth 2.0 · client credentials

For machine-to-machine access, exchange your client_id and client_secret for a short-lived access token. Tokens expire after one hour.

cURL · OAuth token exchange
curl -X POST https://api.autopilotlabs.io/oauth/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=client_credentials" \
  -d "client_id=cli_7Vd9Pk2mQr3L" \
  -d "client_secret=cs_****" \
  -d "scope=agents:write outcomes:read"
JSON · Response · 200 OK
{
  "access_token": "eyJhbGciOiJSUzI1NiIsInR5cCI6...",
  "token_type": "Bearer",
  "expires_in": 3600,
  "scope": "agents:write outcomes:read"
}

Scopes

ScopeTypeGrants
agents:readreadList and inspect agents and their runs.
agents:writewriteInvoke agents, cancel runs, update agent configuration.
outcomes:readreadQuery shipped outcomes, filters, exports.
webhooks:adminadminCreate, rotate, and delete webhook endpoints.

Key hygieneNever embed secret keys in client-side code. Use publishable keys (pk_live_…) for browsers and rotate any leaked key from the console within 60 seconds.

04 · Outcomes

The Outcomes endpoint.

An outcome is a single finished unit of work — a tagged document, a triaged claim, a drafted journal entry. Outcomes are what you pay for, what SLAs are measured against, and what shows up on your invoice. Every outcome carries the full audit trail of the run that produced it.

05 · Webhooks

Webhooks.

Webhooks push events to your endpoint the moment they happen — new outcomes, SLA misses, invoice finalisation. Each event is delivered at-least-once with exponential backoff for up to 24 hours, then dead-lettered to the console for manual replay.

Configuration

Create a webhook endpoint from the ops console or via POST /v1/webhooks. Each endpoint is issued a signing secret. Every delivery is HMAC-signed — verify the Autopilot Labs-Signature header before processing.

cURL · Create webhook
curl -X POST https://api.autopilotlabs.io/v1/webhooks \
  -H "Authorization: Bearer sk_live_****" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://ops.your-team.com/hooks/autopilotlabs",
    "events": ["outcome.shipped", "outcome.sla_missed", "invoice.finalized"],
    "description": "Your ops ingest"
  }'

Event types

EventTriggerPayload root
agent.updatedwriteAgent version or SLA changed.
run.startedwriteNew run has entered the queue.
outcome.shippedwriteOutcome delivered, SLA met.
outcome.sla_missedwriteOutcome delivered late · credit-back issued.
invoice.finalizedreadMonth-end invoice ready for review.
webhook.test—Synthetic ping from the console.

Payload example · outcome.shipped

JSON · Event body
{
  "id": "evt_7Vq2LmKpR3yTnX",
  "event": "outcome.shipped",
  "api_version": "2026-04-01",
  "created_at": "2026-04-16T04:20:04Z",
  "data": {
    "outcome_id": "out_9Lm3VpKqR2yWnT",
    "run_id": "run_4nQ2vP9kL7xTmR",
    "agent_id": "agt_discovery_tagger_v4",
    "status": "shipped",
    "sla_met": true,
    "unit_cost": 320,
    "currency": "AUD",

}

Verifying signatures

HTTP · Delivery headers
Autopilot Labs-Signature: t=1713244804,v1=2e1b8c7a3d1f...
Autopilot Labs-Event: outcome.shipped
Autopilot Labs-Delivery: dlv_8Pk2VmLqR
Content-Type: application/json

Compute HMAC-SHA256 over {t}.{raw_body} with your signing secret, then compare to v1. Reject deliveries where t is more than 5 minutes old to prevent replay.

08 · Errors

Error codes.

Every error is returned with a conventional HTTP status, a machine-readable code, and a human string safe to surface to operators. Errors carry a request_id for support tickets — always log it.

Error envelope

JSON · Envelope
{
  "error": {
    "code": "outcome_cap_reached",
    "message": "Monthly outcome cap of 500,000 reached for ws_meridian_health.",
    "doc_url": "https://autopilotlabs.io/docs#outcome_cap_reached",
    "request_id": "req_8Vq2LpKmR3yTnX"
  }
}

Retry policy

Retry any response where kind=Retryable using full jitter exponential backoff: 1s, 2s, 4s, 8s, 16s, 32s, capped at 5 attempts. Honour Retry-After where present. Never retry 4xx errors — they will not succeed on replay.
