Autopilot Labs — SEO & metadata kit

Reference only. Paste the relevant block into each page's <head> before </head>. One block per page; the JSON-LD Organization block at the bottom goes on the home page only. OG image defaults to /assets/og-default.svg — swap to per-page raster OG cards (1200×630 PNG/JPG) once they exist.

Conventions: canonical URLs use the .html path except the home page (https://autopilotlabs.io/). Descriptions are 140–160 chars, hand-written per page. All OG images are absolute URLs. twitter:card is always summary_large_image.
