v4.6.0

14 Apr 2026 · Major
Major
Agents Ops console Platform

Agents now auto-route across verticals with a new cross-domain planner, plus a full redesign of the ops console for 4K displays.

◆ Added 8 items
  • AddedNew cross-domain planner that lets AI agents hand work between verticals — e.g. a finance agent can now escalate to a legal agent with full context in one hop.
  • AddedAgents auto-retry on SLA near-miss with a 12-second backoff and a warm-path fallback to keep the outcome billable.
  • AddedNew healthcare prior-auth agent (HIPAA-aligned, auto-codes to ICD-11, auto-attaches supporting evidence from the patient chart).
  • AddedOps console redesign: 4K-native layout, a new outcome timeline view, and per-agent cost-per-outcome trendlines.
  • Added"Explain this outcome" button on every row — one click opens the agent's plan, tool calls, and evidence trail.
  • AddedBulk rerun of failed outcomes from the ops console, with optional prompt override for the retry.
◆ Changed 3 items
  • ChangedDefault SLA on the hybrid plan raised from 99.1% to 99.3% — credit-back is automatic, no ticket needed.
  • ChangedAgent memory is now per-workflow by default instead of per-tenant, which cut cross-contamination incidents to zero this quarter.
  • ChangedThe outcome stream API now emits events at the plan step level, not just the outcome level — useful for long-running claims agents.
◆ Fixed 2 items
  • FixedFixed a race where two agents could both claim the same intake fax and double-bill. Now settled via a single-writer lock on the inbox.
  • FixedFixed ops console chart flicker on Safari 17 when streaming more than 200 events/second.

Agents Billing

Quiet fixes for the finance reconciliation agent and tighter rounding on per-outcome invoices.

◆ Fixed 3 items

  • ChangedAI agents assigned to a plan now surface their model provider in the ops console — transparency, not marketing.

Minor
Agents Ops console

Two new legal agents, plus a human-in-the-loop review queue that hands off in under six seconds.

06 Mar 2026 · Security
Security
Security Platform

Mandatory SSO rollout for all ops console seats, plus a tighter egress allow-list for tool-using agents.

◆ Security 3 items
  • SecuritySSO via Okta, Google Workspace, and Entra ID is now mandatory for all ops console seats. Password-only accounts auto-migrate on next sign-in.
