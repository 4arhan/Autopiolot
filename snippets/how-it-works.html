§ 02  —  What actually happens when an Autopilot Labs AI agent runs.

From messy fax to shipped outcome.
In under two seconds.

Every Autopilot Labs deployment is a narrow, boring, well-lit pipeline. A document lands, the AI agent reads it, checks it against the system of record, decides, and writes the result back. No chat. No hand-holding. Below is a real run, from input to audit line, at production tempo.

◆  EVERYTHING IS LOGGED

Every parse, every decision, every write lands in a hash-chained audit trail. You can replay any run to the byte, months later.

◆  KILL-SWITCH IS REAL

One click pauses the agent for a tenant, a route, or the whole pipeline. Humans stay in the loop on anything the policy flags for review.

◆  WE ONLY BILL ON SLA

If the output misses the contracted SLA, the run is free. Outcome pricing means the economics track the work you can actually count.
